# Security policy

## Supported versions

Only the latest release on [PyPI](https://pypi.org/project/FTL-Extract/) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/andrew000/FTL-Extract/security/advisories/new).

Include the affected version, the input files and the `ftl` command that show the problem, and what
you expected to happen. Once a fix is released, the report is credited in the changelog unless you
prefer otherwise.

The scope and severity guidance used for reports are described in
[`.oss-scanner/threat_model.md`](.oss-scanner/threat_model.md).
